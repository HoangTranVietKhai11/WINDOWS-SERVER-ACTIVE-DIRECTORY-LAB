- `06-dhcp-client-ip.png`: Kết quả lệnh `ipconfig /all` trên máy Client nhận IP tự động từ DHCP Scope.
- `07-file-permissions.png`: Cửa sổ phân quyền NTFS & Share Permissions và kết quả kiểm thử truy cập thư mục.
